# Projet final

## Description

Le projet final pour ce cours prend la forme d'un exposé oral de 10 mins fait par chaque étudiant. Le sujet de l'exposé doit être en lien avec l'acoustique, par exemple :

* Présentation du fonctionnement d'un instrument de musique et analyse acoustique correspondante (ex. description du contenu harmonique, type de son, etc.) ;
* Analyse acoustique d'une salle et modélisation acoustique correspondante ;
* Étude autour d'un phénomène psychoacoustique ;
* Etc.

Il est attendu que des diapositives (slides) soient préparées. Ces dernières devront être placées sur le drive suivant (au format PDF) avant la présentation : <https://drive.google.com/drive/folders/1Jrj4khuCZvdRpeecdEA2xZHiHxj496ZD?usp=sharing>.

La présentation doit contenir au moins deux références bibliographiques. 

La présentation sera suivie d'une courte session de questions (5 mins max).

## Format de la présentation

* Diapositive de titre
* Introduction
* Présentation de l'objet de l'étude (contexte)
* Analyse mécanique et acoustique
* Références bibliographiques pour aller plus loin (au moins deux)
* Conclusion

## Critères d'évaluation

* Qualité scientifique (12 pt)
* Qualité des diapositives (4 pt)
* Clarté du discours (4 pt)
